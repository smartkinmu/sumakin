# sumakin
## スマ勤サポートアプリの使い方

### 1. アプリのインストール
* **ブラウザでアプリを開く**: スマートフォンのブラウザで [https://smartkinmu.github.io/sumakin/](https://smartkinmu.github.io/sumakin/) を開きます。
* **インストール**: ブラウザのメニューから「ホーム画面に追加」を選択します。

### 2. アプリの基本操作
* **メールアドレスの設定**: はじめに一度だけ、メニューの「設定」で宛先メールアドレス（スマ勤受付用）を登録します。
* **日付の設定**: 「日付」から作業日の日付を選びます。初期状態は今日の日付です（午前6時までは前日、土日・祝日は前の平日）。
* **勤務時間の入力**: 「始業時刻」と「終業時刻」を設定します。初期値は08:30〜17:15です。
* **中断時間**: 「中断時間・休暇の入力」を開くと、離席などで勤務が中断した時間を最大2件まで入力できます。
* **年休の登録**: 年休を取得した日は「年休」にチェックを入れると始業・終業時刻が入力できなくなります。この状態では「メール作成」ボタンは無効になり、「工数保存」ボタンを押すと年休としてログに登録されます。
* **AM/PM休**: AM休を選ぶと8:30から昼休み開始時刻まで、PM休を選ぶと昼休み終了時刻から17:15まで働いたものとして入力した時刻を加算して計算します。AM休で昼休みより前の時刻、PM休で昼休みより後の時刻を入力すると警告が表示されます。年休と同様に「メール作成」ボタンは無効になり、「工数保存」ボタンを押すとログに登録されます。
* **休憩時間設定**: メニューの「設定」から昼休みと夕休みの時間を変更できます。

### 3. 業務内容の入力
* 各業務について、業務番号、分類、工数、備考を入力します（最大10業務まで）。
* 必要に応じて、画面下部の「表示するグループの数」から業務グループ数を選択できます。入力済みの内容はそのまま残ります。
* 1つ目の業務番号を他の欄へコピーしたい場合は、メール作成ボタン右のメニューから
  「業務1コピー」を選択します。確認ダイアログ承認後にコピーが実行されます。
* その他の機能（更新やログ表示など）は、同じメニューから選択できます。

### 4. 工数保存とメール作成
* **工数保存**: 入力内容の確認と工数の自動補完を行い、その時点の内容をログに登録します。同じ日付のログが既にある場合は上書きされます。見つかった問題点は1つのダイアログにまとめて表示されます。
* **メール作成**: ログに登録したうえで、入力内容を基にメール本文を作成し、メールアプリを起動します。ログ表示画面では、メールを作成した日に封筒のアイコンが付きます。工数が空の業務はメールに含めず、確認のダイアログでお知らせします。

### 5. よくある質問
* **工数の自動補完**: 勤務時間が入力工数より多い場合は、その差を空の工数フィールドに自動的に補完します。
* **分類の文字数**: 分類は5桁の数字に制限されています。
* **業務コードの桁数**: 英字で始まる場合は10桁で入力してください。
* **始業と終業の順序**: 始業時刻が終業時刻より遅い場合は警告が表示されます。日付をまたぐ勤務は入力できません。
* **リフレッシュしても消えない項目**: 端末に保存されたデータ（メールアドレス、業務番号、分類、備考）はリフレッシュ後も残ります。
* **入力漏れ警告**: アプリ起動時に直近2回分の平日ログを確認し、未入力の日があると警告を表示します。
* **最新版への更新**: 各画面の更新アイコン（メイン画面はメニューの「更新」）を押すか、画面を上端から下に引きます。電波のない所では更新せず、それまでの内容のまま使えます。

### ログ表示機能
* メニューの「ログ表示」から、保存された勤務ログを月ごとに確認できます。
* 「納期ログ表示」では任意の開始日と終了日を指定してログを確認し集計できます。
* 各行には日付、始業時刻、終業時刻、勤務時間、残業時間が表示されます。
* ログ画面のゴミ箱のボタンで、ログをすべて削除できます。削除はUNDOボタンで取り消せます。
* ダウンロードのボタンからログをCSV形式で保存できます。ログ表示ではすべてのログを、納期ログ表示では選んだ期間のログを保存します。
* 各行の編集ボタンを押すとポップアップが表示され、日付・始業時刻・終業時刻の編集や削除ができます。ほかにログがある日付には変更できません。時刻を変えずに保存した場合、年休や半休の記録はそのまま残ります。
* 編集のポップアップの「入力画面に戻す」を押すと、その日の日付・時刻・中断時間・業務の内容を入力画面に戻せます。保存だけしてメールを作っていない日に、あとからメールを作るときに使います（この機能を入れる前に保存したログでは、業務の内容は戻りません）。
* ログの上書き（工数保存による同日付の登録）・削除・編集・すべての削除は、直前の1回分をUNDOボタンで取り消せます。別画面に移動したり再読み込みした後でも復元できます。
* 月別集計はこの端末に保存されたログのみを使用して計算されます。
* ログが消失した場合は自動でバックアップから復元されます。
* 「計算チェック」ボタンから、標準休憩時間と中断時間の重なりによる勤務時間・残業時間の計算誤りを検出し、確認のうえ修正できます。修正前の状態はUNDOボタンで元に戻せます。休憩時間の設定を変えた後は、正しく判定できないことがあります。

### バックアップ
* メニューの「バックアップ」から、ログ・設定・業務内容をまとめて1つのファイルに書き出せます。
* 書き出したファイルを選ぶと、その時点の内容に戻せます。復元した後は、同じ画面の「復元を取り消す」で復元する前の内容に戻せます。

### アクセス解析
* 利用状況を把握するため、Google アナリティクスを使っています。入力した勤務時間やログなどのデータは送信しません。
